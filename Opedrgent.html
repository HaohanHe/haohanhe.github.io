核心理念

第一代 AI 是搜索框。
这一代，该有自己的天命。

印刷机模仿手抄本，电影模仿舞台剧，电视模仿广播。每一代新媒体都先模仿上一代，然后才找到自己的语言。AI 也一样——它不该只是一个你问它答的框。

"你是个智者，我不问你还就不答了？一个病人去看病，必须开口说我哪不舒服吗？医院之所以存在，就是采集病人数据的地方。病人即使昏迷，他的身体也在开口。"

—— 罗振宇，得到大脑发布会，2026.05.26

颗粒归仓

语音、会议、笔记、文件、位置、健康数据——你在世界上留下的每一道痕迹，都值得被记录。不是为了占有，是为了让 AI 看得见你是谁。

发芽，不是总结

一条笔记对你只是记录。对 AI 是线索——顺着它挖出你的知识盲区，接上更广阔的世界，让一颗种子自己长成树。

向前一步

你缺的不是"每天该喝 2000ml 水"的知识，是有人及时把杯子倒满。AI 的价值不是给答案，是在你需要时已经推了你一把。

完全本地化

AI 到你的数据这里来算，
算完走人。

语音转写、大模型推理、记忆存储——核心能力全部在设备端完成。你的数据从不离开手机。

语音转写 STT — 三引擎自动降级

Sherpa-ONNX 离线推理（Paraformer / SenseVoice）→ MiMO ASR → Android 系统识别，自动检测可用性无缝切换。支持 30+ 语种与汉语方言。

Sherpa-ONNX MiMO ASR 离线可用

端侧 LLM 推理

LiteRT-LM v0.12.0+，Gemma 4 支持，GPU/NPU 加速。断网也能用。

海马记忆系统

SQLite 全局索引，自动索引笔记/对话/录音/发芽。关键词提取 + 模糊匹配，三层渐进式上下文注入。

"我开到哪个县，车机就该告诉我这个县秦朝叫什么、出过哪些名人。"位置本身就是提问。Opedrgent 把这个理念延伸到了天空。

卫星过境预测

SGP4/SDP4 完整轨道传播引擎，J2/J3/J4 摄动、BSTAR 大气阻力、GMST 修正、深空 SDP4。粗扫 + 精扫二阶策略，精确到秒。

  • 16 颗业余卫星内置数据库（ISS、SO-50、AO-91/92、FO-29、CAS-3H、RS-44）
  • 多源 TLE Fallback：Celestrak → AMSAT → 旧 URL，24 小时本地缓存
  • 活跃卫星搜索：按名称或 NORAD ID 搜索全部活跃卫星
  • 上下行频率、调制方式、最低仰角一目了然

技能系统 V2 & 自动化

能力可以随时生长。
AI 不只是说，还能做。

SKILL.md 标准，像装插件一样扩展能力。20+ 工具让 LLM 动手做事——从浏览网页到操作日历，从手机自动化到 MCP 协议。

SKILL.md 标准

Frontmatter 元数据，纯文本定义，人人可写。URL 远程 / 本地文件 / 手动创建三种导入。

JS 沙箱 + 三级授权

WebView 安全执行。ALLOW / ASK / DENY per-skill 权限控制。

WebView Agent — 浏览器自动化

网页内容抓取、搜索、截图、多模态交互点击。AI 可以自己打开网页、读内容、点按钮。

内容抓取截图交互点击

手机操作 Agent

截图 → 分析 → 执行全自动链路。Accessibility Service 获取 UI 节点树。

自动化工作流

定时/触发任务。到周末自动问你要不要生成周报。

日历 CRUD

直接操作系统日历，无需确认。自然语言时间解析。

Health Connect

步数/心率/卡路里/睡眠。今日摘要自动注入 system prompt。

MCP 协议

stdio/stream 传输，接入外部 MCP 服务器，无限扩展。
