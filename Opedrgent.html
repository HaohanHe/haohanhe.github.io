核心理念

AI 不该是个搜索框

第一代 AI 模仿搜索引擎，给你一个框，有问题你问。但这不对——就像电影不该模仿舞台剧，电视不该模仿电影院。AI 时代的人机交互，应该有自己的天命。

"你是个智者，你怎么能这么对我呢？我不问你还就不答了，我问的水平不高，你还就敷衍我了，有这么当智者的吗？……一个病人去看病，他必须开口对医生说我哪哪不舒服吗？医院之所以存在，就是一个采集病人数据的地方。病人即使不开口，他的身体也在开口。"

—— 罗振宇，得到大脑发布会，2026 年 5 月 26 日

颗粒归仓

语音、会议、笔记、文件、位置、健康数据——你行走在世界上的所有痕迹，尽可能记录下来。不是为了占有，而是为了让 AI 看得见你是谁。

发芽，而非总结

一段录音、一条笔记、一个随手的念头，对你只是记录。对 AI 是线索——顺着它，帮你挖出知识盲区，接上更广阔的知识，让一颗种子长成参天大树。

向前一步，助推

你缺的不是"每天该喝 2000ml 水"的知识，缺的是有人及时把杯子倒满。AI 的价值不是告诉你答案，而是在你需要的时候，已经推了你一把。

完全本地化

AI 到你的数据这里来算，算完走人

语音转写、大模型推理、记忆存储——核心能力全部在设备端完成。你的数据从不离开手机。

语音转写 STT

Sherpa-ONNX 离线推理（Paraformer / SenseVoice）+ MiMO ASR + 系统识别，三引擎自动降级。支持 30+ 语种与汉语方言。

端侧 LLM 推理

LiteRT-LM v0.12.0+ 集成，支持 Gemma 4 等模型，GPU/NPU 加速。离线模式自动降级，断网也能用。

海马记忆系统

SQLite 全局索引，自动索引笔记、对话、录音、发芽、面试、用户偏好。关键词提取 + LIKE 模糊匹配，三层渐进式上下文注入。

核心功能

不只是对话，是一整套主动服务

从全双工语音对话到卫星过境预测，从知识发芽到自动化工作流——Opedrgent 把 AI 的主动性落到每一个具体场景。

全双工语音对话

Interview Mode：AudioRecord||AudioTrack + 硬件 AEC + VAD + BargeIn + 5 状态 FSM，接近真实对话的边说边听体验。

会议自动纪要

说话人分离 + 多人语音转文字 + MeetingTranscriber 持久化。录音中可拍照关联时间点，支持系统内录。

知识发芽引擎

四阶段洞察引擎：种子提取 → 跨域关联 → AHA 洞察 → 金句回响。叙事式文章输出，非结构化要点。

多引擎 ASR 容错

Sherpa-ONNX（离线）→ MiMO ASR → Android SpeechRecognizer，自动检测可用性无缝切换。

编辑团队协作

EditorTeamService 多角色编辑管道，Skill 深度集成，SkillModelUnifier 模型统一。

声纹识别 & TTS

三引擎 TTS 路由：System TTS + StepAudio TTS（Global+Inline）+ MiMO TTS。StepRealtimeClient WebSocket 实时语音。

系统内录

MediaProjection 捕获系统内部音频（Android 10+），无需 Root。前台服务保活，不被电话中断。

AI 自然语言搜索

海马记忆全局检索 + 知识库 RAG 向量存储。以任何维度、任何刁钻的角度调取你的记录。

多模型对话

双协议 LLM：OpenAI Chat Completions + Anthropic Messages。流式 SSE 输出 + Thinking Mode + JSON Mode。

20+ 工具调用

搜索、URL 读取、JS 执行、日历 CRUD、健康数据、Intent 调度、反向地理编码、报告生成……Function Calling + System Prompt 双通道发现。

深度研究

DeepResearchTool 多步搜索 + 网页阅读 + 自动总结。HybridRankingEngine 混合排序 + 语义评分 + 动态权威评分。

文档处理 & OCR

PDF 处理 + ML Kit 中英文 OCR + PP-OCRv6。DOCX 处理。导入即转写，扔进去就能整理。

Ham 模式 · 业余卫星通信

走到哪，AI 就把知识告诉你

"我开到哪个县，车机就应该告诉我这个县秦朝叫什么、出过哪些名人。"——位置本身就是提问。Opedrgent 把这个理念延伸到了天空。

卫星过境预测

SGP4/SDP4 完整轨道传播引擎，支持 J2/J3/J4 摄动、BSTAR 大气阻力、GMST 修正、深空 SDP4。粗扫 + 精扫二阶策略，精确到秒。

  • 16 颗业余卫星内置数据库（ISS、SO-50、AO-91/92、FO-29、CAS-3H、RS-44 等）
  • 多源 TLE Fallback：Celestrak → AMSAT → 旧 URL，24 小时本地缓存
  • 活跃卫星搜索：按名称或 NORAD ID 搜索全部活跃卫星
  • 上下行频率、调制方式、最低仰角一目了然

技能系统 V2

能力可以随时生长

SKILL.md 标准，像安装插件一样扩展 AI 的能力。JS 沙箱安全执行，远程 URL 动态加载，不重启 App 即可更新技能。

SKILL.md 标准

Frontmatter 元数据：name / description / version / category / require-secret。纯文本定义，人人可写。

JS 沙箱执行

WebView + GalleryBridge 回调，资源/CPU/网络限制。ai_edge_gallery_get_result() 标准化回调接口。

三种导入方式

URL 远程加载 / 本地文件导入 / 手动创建。Skill Marketplace 从远程动态加载技能定义。

三级授权

RequireSecretManager：ALLOW 自动允许 / ASK 每次询问 / DENY 禁止调用。per-skill 权限控制。

内置 JS Skills

calculate-hash（哈希计算）、mood-tracker-lite（心情追踪）、interactive-map（交互地图）、qr-code（二维码）、virtual-piano（虚拟钢琴）。

内置 Text Skills

critical-inquiry（批判性探究）、insight-sprout（知识发芽）、insight-review（洞察评审）、text-refine（文本精炼）、mimo-tts、multi-agent-collaboration。

工具调用 & 自动化

AI 不只是说，还能做

20+ 工具让 LLM 可以动手做事。从搜索网页到操作日历，从浏览器自动化到手机操作 Agent——AI 的主观能动性，在这里兑现。

WebView Agent

浏览器自动化引擎：网页内容抓取、搜索、截图、多模态交互点击。AI 可以自己打开网页、读内容、点按钮。

手机操作 Agent

StepMobileAgentTool：截图 → 分析 → 执行全自动链路。Accessibility Service 获取 UI 节点树，操作历史记录与回放。

自动化工作流

AutomationWorker + AutomationStore，可配置定时/触发任务。到了周末自动问你要不要生成周报，发了运动数据自动存健康记录。

日历 CRUD

ContentProvider 直接操作系统日历，无需用户确认。自然语言时间解析："明天下午3点"、"一小时后"、"下周一"。

Health Connect

步数、心率、卡路里、距离、睡眠、运动。今日摘要自动注入 system prompt，AI 知道你今天走了多少步、睡得好不好。

MCP 协议支持

McpManager / AgentService MCP 协议层，stdio/stream 传输。可以接入外部 MCP 服务器，无限扩展工具能力。

多智能体编排

不是一个 AI，是一支团队

AgentSwarm 任务分解，MultiAgentOrchestrator 多智能体编排。/orchestrate 指令一键启动研究者、分析师、编辑者协作。

AgentSwarm

复杂任务自动拆分为子任务，分配给专业 Agent。Agent 间统一消息格式和上下文传递机制。

MultiAgentOrchestrator

预设角色池：研究者 / 分析师 / 编辑者。Research Agent 深度研究：WebResearchRouter + HybridRanking 完整链路。

编辑团队

EditorTeamService 多角色编辑管道。Skill 深度集成，EditorTeamSkillAdapter + SkillModelUnifier。

多模态工具

图像生成 / 编辑、图生图、视频摘要、图像理解（step-1o-turbo-vision）、RAG 检索。
